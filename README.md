# FixPro Склад — страница для тестеров

**Демо-склад (общий, только примеры):**
https://sorvingbel-hue.github.io/fixpro-sklad-app/#s=demo&k=fixpro-demo-public-2026-sklad

**Свой склад:** откройте https://sorvingbel-hue.github.io/fixpro-sklad-app/ и нажмите «Создать свой склад». Код склада создаётся в вашем браузере, ссылку для бригады страница покажет сама. У кого ссылка — у того полный доступ к складу, храните её как пароль.

Статус: **пилот, не защищённая система уровня SaaS.** Данные общие (несколько телефонов видят одно и то же), сервер пускает в склад только по его коду, склады отделены друг от друга. Личных входов, ролей и журнала доступа пока нет. Настоящие данные клиентов в демо-склад не вносить.

Исходники, схема базы и тесты — в закрытом репозитории `fixpro-sklad` (коммит 4da4862).
